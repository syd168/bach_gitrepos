使用 Personal Access Token 访问仓库列表；删除需额外权限，见右侧说明。

登录并加载仓库

输入框为密码样式，降低被旁人窥屏风险。

任选一种令牌类型；删除仓库必须包含对应权限。

Classic（经典）令牌

  1. 打开 GitHub → Settings → Developer settings → Tokens (classic)，点击 Generate new token (classic)。
  2. 勾选 repo，并单独勾选 delete_repo（仅 repo 不含删除权限）。
  3. 生成后立即复制保存。

Fine-grained（细粒度）令牌

  1. 打开 Generate new fine-grained token。
  2. 在 Repository permissions 中将 Administration 设为 Read and write。
  • 令牌等效于密码，勿提交到 Git、勿随意外传。
  • Token 保存在服务器会话中，请勿在公共设备使用；用毕请退出登录。
  • 仅在可信网络访问；远程部署请使用 HTTPS 并保管 FLASK_SECRET_KEY。
  • 遵循最小权限，完成后可撤销或轮换 Token。
